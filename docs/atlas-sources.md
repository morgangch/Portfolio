# Données de la carte Territoires

Vérification éditoriale : 2 octobre 2026.

La carte utilise `atlas-data.js`, chargé avant `atlas-map.js`. Ce jeu de données est embarqué : l’exploration ne dépend pas d’un appel GitHub côté navigateur. Les positions et les connexions sont conceptuelles ; les liens indiquent des domaines communs ou des réalisations associées, pas des flux réseau.

## Limites éditoriales

Les README décrivent des projets, sans certifier toutes les fonctionnalités par exécution du code. PASSSSI est présenté comme une architecture décrite ; eventd distingue les phases futures ; Minishell2 est explicitement incomplet. Les chiffres de production reprennent le portfolio existant et ne sont pas des mesures en direct. Aucun pourcentage de maîtrise ou niveau de compétence n’est inventé.

## Mise à jour

Une fiche contient un identifiant stable, une catégorie, ses domaines, un résumé, des technologies, des détails, des repères chiffrés contextualisés, des connexions et ses sources. `point` ajoute un repère secondaire SVG au zoom. Les repères historiques restent définis dans `index.html` ; les fiches, l’index et les nouveaux repères partagent les mêmes données.

Après une modification, contrôler la syntaxe JavaScript, la cohérence des identifiants et des connexions, puis vérifier la recherche, les filtres, les couches, les fiches, le zoom, la navigation clavier, les liens `#atlas/identifiant` et l’affichage mobile.
